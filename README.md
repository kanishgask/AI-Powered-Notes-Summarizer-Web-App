# AI-Powered Notes Summarizer

## 📌 Overview
This project is a web application that summarizes long notes into concise summaries using Natural Language Processing (NLP).

## 🚀 Features
- Paste long notes and get instant summaries
- Uses state-of-the-art transformer model (BART)
- Clean and simple UI
- Fast and efficient

## 🛠 Tech Stack
- Python (Flask)
- HuggingFace Transformers
- HTML, CSS

## 📊 How It Works
1. User inputs long text
2. Text is cleaned and preprocessed
3. Transformer model generates summary
4. Output displayed on UI

## ▶️ Run Locally
pip install -r requirements.txt  
python app.py
